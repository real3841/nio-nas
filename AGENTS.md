# AGENTS.md

Working notes for agent sessions in **nio-dash-nas** — the NAS build of the NIO vehicle dashboard.

## What this repo is

- A long-running NAS service: 24/7 data collection + a web dashboard. `scripts/serve-web.ts` serves `dist/` and proxies `/api/*` to `scripts/app-server.ts`.
- Runtime data lives outside the repo (`/workspace/nio-dash/data`); secrets live in `deploy/.env` (mode 600, never committed; template in `deploy/.env.example`).
- The desktop app is a **separate repo**. Electron / native / tray code still present here is macOS-only legacy and is being stripped.

## Commands

| Command | What it does |
| --- | --- |
| `npm run typecheck` | `tsc --noEmit`; must pass before a change counts as done |
| `npm run build` | Vite build to `dist/` |
| `npm run serve:web` | Run the web server on 8788 (app-server on 8789) |
| `sh run-nas.sh status` / `restart` | Inspect / restart the guarded NAS service |
| `npm run tracks:fetch -- --months N` | Backfill tracks |
| `npx tsc --noEmit` | Same as typecheck |

Verification for a change: `npm test` + `npm run typecheck` + `npm run build`. Tests run with `node --import tsx --test` (see `package.json`).

## Rules

- Never commit `deploy/.env`, `data/`, `*.log`, `node_modules/`, `dist/`.
- Never put secret values (tokens, API keys, cookies) into source, docs, tickets, or commit messages — reference names only.
- Keep the existing visual tokens and information architecture unless a ticket explicitly changes them.
- One vertical slice at a time; no big-bang rewrite.
- New dependencies are a decision, not a convenience — say why in the ticket.

## Notes

- Commit messages: Chinese, one line, prefixed (`feat(nas):` / `fix(nas):` / `docs:`).
- Data and secrets never enter git; check `git status` before committing.
- The public README uses only synthetic demo GIFs under `docs/assets/` (generated by `scripts/readme-city-gif.mjs`).
